# Changelog

## [Unreleased]

### Added

- A profile picture for every account. Settings → General shows it at the head of the Account card: click it to pick a photo, and once there is one the same click opens a small menu to pick another or go back to initials. The photo is cut to its centre square and shrunk to 256 px in the browser, so only a small WebP (JPEG where the browser cannot write WebP) is uploaded. The picture replaces the initials on the rail's account button, in Settings → Company's member list, in Friends and in group-chat member lists, for everyone who shares a company with the member, their friends, and people they sent a friend request to (a request someone else sent does not reveal the picture until it is accepted). Pictures are private storage objects the cloud only hands to those people, and only the current one (migration `20260924150000_member_pictures`); an account's folder holds four objects at most, and uploads that never became the picture are cleaned up by the owner's browser; the cloud refuses to delete the current picture. The page shows pictures through `blob:` URLs, so its image policy is unchanged. Where the cloud has no member pictures yet, the disc stays initials with nothing to click.
- Choose the model and the thinking effort for one agent thread in the composer's ··· → Model menu: GPT-6 Astra, GPT-6 Sol or GPT-6 Luna (GPT-5.6 Sol and Terra are gone; a thread that used them goes back to the agent's default model) and Low, Medium or High effort (runtime bundle v91). The menu row shows both, for example "GPT-6 Sol · High". The choice belongs to that thread only and applies from the next message; routines and other threads keep their own. Choosing only an effort keeps the thread on its default model. Until the cloud honours per-thread effort, the Effort group stays hidden and only GPT-6 Astra can be chosen.
- The whole web app is offered in English and Danish. Choose the language in Settings → General (Follow system uses the browser's language); the screens redraw in the new language at once, a message being written and chosen images stay, and Settings stays open on the same tab. Every screen is translated: the agent list, conversations and the composer, cards and failed runs, new conversation, agent and group details, routines, coding sessions, Settings, sign-in, the Company File (also the live browse, edit and upload panel), organization and the computer screen's own controls. Names, messages, file names and server error text stay as written. Danish follows the wording on qorpera.com ("Virksomhedsfilen", "Co-Founder"). The tests fail when interface text has no Danish or English is left unwrapped where interface text goes.
- Settings → General → Language & region shows Language and a new Time zone as small buttons in one card, as the desktop reference does. Each opens a list with a search field and a check on the current choice: languages by their own name with the name in the interface language beside it, time zones by city with today's offset beside it (a zone is also found by region or by its name, such as "Central European Time"). Both start at Follow system. A chosen zone sets the clock for message times, the day breaks in a thread and the times in lists and cards, and new routines start in it; the screens behind Settings redraw at once and keep a message being written. Like the language, it is kept in this browser.
- Right-click an agent in the rail for Grok Bot's menu: Pin, Move to (the company's sections, Unassigned, New section), Rename, Copy conversation ID, Hide from sidebar and Delete (runtime bundle v90). Pinned agents stand as square cards right under the Co-Founder card; the company's sections follow, then Unassigned with the group chats. Right-click a section's title to rename or delete it, or an empty spot in the rail for a new section. Drag an agent to reorder it, move it to another section, or pin and unpin it; the place it will land lights up, with no border, and a thin line marks the spot. Sections are the company's and agents move each other between them too; pins and hidden agents are yours. A touch screen opens the menu with a long press. Before the cloud has the sidebar, the rail stays one list and the menu offers Rename, Copy conversation ID and Delete.

- Connect Gmail, Google Drive and GitHub for the company in Settings → Connections → Services (runtime bundle v87). A connection belongs to the company: owners and admins connect it by signing in with the service (or, for GitHub, a pasted token) or disconnect it, every agent in the company can use it from its next run, new hires included, and the card names who connected it. A sign-in finishes only in the browser tab that started it, so a consent link passed to someone else connects nothing, and a crafted return link does nothing. Other members see the services read-only. The sign-in goes to the company's secret broker behind the shared broker origin (`?company=` routes it); no token reaches the web app or the database.
- Cards an agent raises in its thread (kernel bundle v70, runtime v71): a question with options, a computer takeover with Take over, I'm done and Skip, and the approval card's Approve and Decline now record the decision. A card shows who answered and what, stays in the thread once answered, and expires on its own time. Form and draft cards show their content and can be declined or discarded; filling a form waits for the vault fill step. A secret card takes the value in a masked field and saves it into the company's cloud vault straight from the browser (owners and admins for the company, other members for themselves; a saved secret with the same name is replaced), then marks the card provided; the agent only learns that it was saved. Group chats never carry cards.

### Fixed

- A right-click in the rail during the page's first 800 ms opens the agent or section menu; the long-press guard swallowed it before any press had opened one, which also made the rail menu tests fail at random in CI.
- Changing the figure of an agent that wears its figure's own colour now gives it the new figure's own colour, until a colour is picked in the same picker; a picked colour is kept through every figure. The first-run page keeps a colour chosen in the agent's details unless a different figure is picked there.
- Show grey placeholder shapes while a screen loads instead of a line such as "Opening company" or "Loading conversation". The company list, Team, Friends, group details and Company File do the same. Placeholders stand in only for a first read: a refresh keeps what the page already shows. The shapes breathe together and stay still with reduced motion; a screen reader still hears what is loading. The Company File page now says when membership could not be read instead of waiting forever, and a start-up that cannot reach the cloud shows the error with Try again.
- Let the Co-Founder's colour be changed: its figure picker in the agent details offers the colours and Reset like any agent's, and the rail, header and group pictures draw the colour chosen. A Co-Founder whose colour nobody has picked keeps its figure's own shade.
- Keep keyboard focus in Settings → General when the account plan finishes loading; the page is redrawn only when the error or message it shows changes.
- Show a failed or stopped run as one line right above the composer, in the same band as the company notices, instead of at the end of the thread. The thread keeps only the conversation; the card keeps its reason, Try again and Dismiss. Opening a conversation while such a line, or the composer, appears no longer leaves the thread a little short of its last message.
- Show the composer's "Chat settings and more" button in group chats too. Its menu keeps Attach files greyed out with a note that images are not supported in group chats and to use Company File; the model choice stays with single-agent conversations.
- Entering an agent's computer shows the guest screen inside a thin frame in full screen, a computer inside a computer, with the agent's name on the left and one exit button on the right, the exit-full-screen glyph named "Back to thread"; the separate toggle is gone. If the browser refuses full screen, or never answers, the same frame opens over the thread and says "Full screen unavailable"; the next Enter asks again.
- Make thread and rail text sharper and easier to read, above all on the dark theme and on 1x screens: the thread and composer are set in the system face (San Francisco on a Mac, as Messages and the rail already are) at 16px on a 21px line with no sub-pixel letter-spacing, the page renders without macOS font dilation, dark bubbles carry white text on a darker grey, dark text tokens are brighter, and rail role lines and timestamps step up a size and weight.
- Show what an agent is doing in its conversation the way the desktop does: hovering or focusing the working figure at the end of the thread reads "Nova is working" or "Nova is writing" with the ink wave, and the row no longer relies on a browser tooltip. The rail card's "Working" and "Writing" carry the same wave, and every wave on the page runs on one clock, so the card and the thread caption move together.
- Preserve agent metadata drafts and retry state across details-panel closes, serialize saves, and retire confirmed edits when the roster catches up so later changes by other members are not overwritten.
- Keep keyboard focus on an available execution-notice action when refreshes remove the previously focused control.
- Keep the rail's "Needs you" for runs waiting on a member decision, including a failed run that left Company File changes. An agent with a failed or stopped run nobody has dismissed now rests idle with a red status disc, the opposite of the green working disc; the rail link names the state in words, also in the compact rail.
- Render room replies with immutable server-projected staff identity and preserve accepted human messages even when no agent is eligible.

- Use a length-neutral email code hint so sign-in instructions remain accurate with the configured eight-digit codes.
- Submit team-room messages through the public room-post contract, preserve room retry identity, and match room attachments/run displays to the supported interfaces.
- Keep the rail's search field, keyboard focus and scroll position when the rail refreshes: dead-key, IME and phone-keyboard typing is no longer broken, and a collapsed rail stops filtering by a search it hides until it opens again. A refresh rebuilds only the rows that changed, so moving between agents keeps their figures and an error notice is not announced again, and figures repaint sharp when the window moves to a screen of another pixel density.
