# Changelog

## [Unreleased]

### Breaking Changes

- Coding sessions stand by between turns: the guest configuration is `qorpera.coding-command-guest/v4` (its resource profile names only `maxLogBytes`), command requests are `qorpera.coding-command-request/v2` (`timeoutMs` may be null), and guest leases are `qorpera.coding-guest-lease/v2`, one generation per session attachment with the current turn and whether it is open. A new turn no longer stops the session's commands; a new attachment does. The turn context is `qorpera.coding-turn-context/v2` with `commands` (still running, stopped since the previous turn).
- The unreleased office unit now loads credentials from the current boot's immutable directory. Previously acknowledged installations without those files are refused; replay does not backfill missing credentials from the original installation.

- Added the native host's entry points without the service-role key (G2-1; migration `20260928409985`, SQL tests 792 and 793; inert until the native host uses them in G2-2): `qorpera_native_host_call(p_job_id, p_job_lease_token, p_name, p_args)` and, for the lease validator only, `qorpera_native_host_call_long` with the same arguments. When the object gateway answers 409 (or 503) with `code: "lock_conflict"` (a serialization failure, deadlock or lock timeout on the company's rows, rolled back, nothing committed), `HttpNativeCompanyObjectTransport` retries at most twice, after 100–300 ms and then 300–700 ms, and only when the pause and an attempt as long as the last one (a lock timeout answers after the whole 2 s lock wait; never counted below 500 ms) end inside the tool call's 5 s budget, or the transport's own deadline if shorter. Both requests are safe to repeat: a GET only reads and runs both authority checks again, and a PUT is addressed by its content, so the second attempt finds the same bytes ("exists") and its confirmation writes the same catalog row. Denials, stops (423), other 409s (a GC fence, a deletion in progress), other 503s and stalled or lost answers are never repeated, and a denial's body is still never read.
