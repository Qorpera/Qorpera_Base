# pr-loop ready-to-merge check

Throwaway file for checking that a review with no findings is marked ready to merge and merged automatically. It never reaches master.

A Gregorian leap year is divisible by 4, except century years, which must also be divisible by 400:

```js
const isLeapYear = (y) => y % 4 === 0 && (y % 100 !== 0 || y % 400 === 0);
```
